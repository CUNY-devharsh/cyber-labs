About this machine

What runs
A real Linux kernel on an emulated 64-bit PC. The emulator is QEMU, compiled to WebAssembly with qemu-wasm.
System
Kali rolling packages, 64-bit, on the Kali kernel.
Sign in
You are signed in as kali. The password is kali and sudo does not ask for it.
Network
None. The machine cannot reach the internet or your network.
Your files
Keep your work in ~/labs. Send a file puts a file there and Get a file downloads one from there. Press Save my files before you close the tab. The page puts the saved files back the next time you open it in this browser.
Everything else
The rest of the machine starts fresh every time. Programs you install and files outside ~/labs are gone when the tab closes.
Speed
Much slower than a real computer, and slower than the 32-bit machine. A debugger takes about half a minute to start. Use a cloud machine for heavy tools, the Kali desktop, or Windows Server.
Copy and paste
Select text and press Ctrl+C to copy it. Press Ctrl+V to paste. On a Mac, use Cmd.
