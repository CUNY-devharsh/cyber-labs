About this machine

What runs
A real Linux kernel on an emulated 32-bit PC. The emulator is v86, written in JavaScript and WebAssembly.
System
Kali rolling packages, 32-bit, on the Linux 6.1 long-term kernel from Debian.
Sign in
You are signed in as kali. The password is kali and sudo does not ask for it.
Network
None. The machine cannot reach the internet or your network. Run lab-targets for practice targets inside the machine.
Your work
It lives in this tab's memory. Press Save machine before you close the tab. The save stays in this browser on this computer.
Speed
Slower than a real computer, because every instruction is emulated. Use a cloud machine for heavy tools, the Kali desktop, or Windows Server.
Copy and paste
Select text and press Ctrl+C to copy it. Press Ctrl+V to paste. On a Mac, use Cmd.

This is an unofficial build for this course. Kali Linux is a trademark of OffSec, which does not publish a 32-bit kernel.
